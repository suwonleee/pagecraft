# Pagecraft

[English](../README.md) · [한국어](README.ko.md) · [简体中文](README.zh-CN.md) · **日本語**

**AI が作った HTML を、自分らしく仕上げよう。**

レポート、ランディングページ、静的なモックアップを開き、見出しや配置を直して通常の HTML として保存できます。ページの再構築や AI による文書全体の再生成は不要です。編集にアカウント、API キー、AI のサブスクリプションは必要ありません。

[**ブラウザーで試す →**](https://suwonleee.github.io/pagecraft/)

![実際の英語 UI：レポートのテキスト、スタイル、配置を編集](../docs/images/edit-report.png)

## 活用例

### AI の下書きを共有できるレポートに

**レポート**から**週次レポート**や**意思決定メモ**を選ぶか、AI ツールの完全な HTML を貼り付けます。文章をダブルクリックして直し、プロパティでフォントサイズ、色、余白を調整して HTML をダウンロードします。テンプレートには意味のある要素 ID、レスポンシブな配置、A4 の印刷ルールが含まれています。

![英語のレポートテンプレート、HTML 貼り付け、AI への作成依頼](../docs/images/report-templates.png)

1. **レポート → 週次レポート**を選びます。
2. タイトルをダブルクリックするか、プロパティの**テキスト**で変更します。
3. **テキストスタイル**、**色**、**サイズと余白**を調整します。
4. **HTML をダウンロード**し、開き直して結果を確認します。

テンプレートは架空の例です。共有前にサンプル文と角括弧の内容を実際の資料に置き換えてください。Pagecraft は指標を作り上げたり、AI サービスを呼び出したりしません。

### ビルドなしでランディングページを調整

**サンプルを試す**から見出しやボタンの文言を変え、デスクトップ・タブレット・モバイルの幅で確認できます。移動、サイズ変更、複製、削除、整列、取り消しに対応しています。

![実際のキャンバスで英語のランディングページを編集](../docs/images/edit-landing.png)

保存結果は通常の HTML です。ブラウザーで開き、Git で管理し、自分の静的ホスティングで公開できます。画像は実際の英語 UI で撮影しています。アプリのメニューから日本語に切り替えられます。

## ローカルで始める

ローカルビルドには **Node.js 22.12 以降**と npm が必要です。`.nvmrc` は Node.js 24 を指定しています。

```sh
git clone https://github.com/suwonleee/pagecraft.git
cd pagecraft
npm ci
npm run build:web
npm run serve:web
```

**http://127.0.0.1:4318/** を開き、レポートやサンプルから始めるか、自分の HTML を読み込んでください。

### 言語設定

初期言語は英語です。上部の **エディターの言語** メニューで **English / 한국어 / 简体中文 / 日本語**を選ぶと、メニュー、案内・エラーメッセージ、新しいレポートのテンプレート、サンプル、AI への作成依頼が切り替わります。メニューのアクセシブルな名前とツールチップも現在の言語で表示します。読み込んだ文書の内容は翻訳しません。

設定はブラウザーの `localStorage` に `pagecraft-language` というキーで保存します。値は `en`、`ko`、`zh-CN`、`ja` です。ブラウザープロファイルとサイトのアドレスごとに独立し、同期やサーバー設定、アカウントは不要です。未設定または未対応の値は英語になります。サイトデータを消去すると設定もリセットされます。

言語を切り替えるとエディターを再読み込みし、現在の文書を閉じます。文書が開いていれば、保存済みでも言語切り替え専用の確認画面を表示します。初期フォーカスは **キャンセル** にあり、取り消すと文書と編集内容をそのまま保持します。切り替えを確定する前にファイルを保存してください。オフラインの準備が完了したウェブアプリと、任意で導入する拡張機能には 4 言語すべてが含まれます。

### 用途に合ったモード

| モード | 用途 | 保存方法 |
|---|---|---|
| ブラウザーアプリ | 単体で完結する HTML | 対応ブラウザーでは許可した元ファイルに保存。読み込んだコピーはダウンロード |
| ローカルフォルダーサーバー | CSS・画像・フォントが隣にある HTML | 指定したフォルダー内に保存し、バックアップと競合を確認 |
| インストールしたウェブアプリ | アプリアイコンから起動 | ブラウザーと同じ権限。対応環境では「このアプリで開く」から HTML を渡せる |
| 任意の拡張機能 | Chrome のツールバーから起動 | 独立したファイル編集。現在のウェブサイトを取得・変更しない |
| 文書 CLI | エージェントと自動化 | ハッシュ検証後に元ファイルを更新、または別のコピーを作成 |

```sh
npm start -- ./drafts
npm start -- ./report.html --port 4319
```

フォルダーモードの標準アドレスは **http://127.0.0.1:4317** です。サーバーは起動したままにしてください。パスなしの `npm start` は `.pagecraft/` に入門文書を作成します。この初期文書と CLI の出力は英語です。

### 保存は明示的に行います

- HTTPS または localhost の Chromium 系ブラウザーでは、元ファイルを開いて権限を許可すると直接保存できます。
- コピーの読み込み、HTML の貼り付け、テンプレートの場合は編集後にダウンロードします。元ファイルは上書きせず、元ファイルの未保存状態も解除しません。
- ブラウザーの一時的な下書きは別のコピーとして復元できますが、ファイル保存の代わりにはなりません。

ブラウザーモードは最大 **16 MiB** の UTF-8 HTML ファイル 1 つに対応します。隣のファイルを自動で読み込めないため、HTML に埋め込むかフォルダーモードを使用してください。[保存・復元とブラウザーの違い（英語）](../docs/USAGE.md)

## コーディングエージェントと同じファイルを編集

見た目の判断はキャンバスで、正確な部分修正は Claude Code や Codex などのエージェントで行えます。CLI は保存済みファイルを処理し、起動中のエディターサーバーや AI 提供元の SDK は不要です。

```sh
npm run --silent document -- inspect ./report.html --query weekly-summary-lead
```

エージェントへの依頼例：

> `docs/AI_EDITING.md` を読み、`report.html` の要約を短くしてください。それ以外のテキスト、スタイル、ID、印刷ルールは保持してください。書き込む前にパッチを検証し、文書全体を再生成しないでください。

検査結果のハッシュを使って `edits.json` を作成します。

```json
{
  "version": 1,
  "hash": "REPLACE_WITH_THE_HASH_FROM_INSPECT",
  "changes": [
    { "target": "weekly-summary-lead", "text": "主要なフローはレビュー可能です。効果は引き続き測定中です。" }
  ]
}
```

```sh
npm run --silent document -- apply ./report.html --patch edits.json --dry-run
npm run --silent document -- apply ./report.html --patch edits.json --write
```

**引き継ぐ前に画面上の編集を保存し、エージェントの書き込み後は文書を開き直してください。** 古いハッシュは拒否され、`--write` は前のファイルをバックアップします。競合確認を伴う順番の引き継ぎであり、リアルタイムのマージではありません。[エージェントの作業手順（英語）](../docs/AI_EDITING.md)

## 拡張機能と静的デプロイ

```sh
npm run build:extension
```

Chrome の `chrome://extensions` でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」で `extension-dist/` を選択します。Pagecraft のアイコンを押すと起動します。ホスト権限やコンテンツスクリプトは使用しません。拡張機能ストアへの掲載はありません。

`npm run build:web` で生成した `web-dist/` は静的ホストに配置できます。HTTP(S) で配信し、サブディレクトリの URL は `/` で終わるようにしてください。**`file://` で index.html を直接開く方法には対応していません。** ブラウザーがモジュールと worker をブロックするためです。ビルド済み ZIP の有無は [Releases](https://github.com/suwonleee/pagecraft/releases) を確認してください。

## 主な操作と制限

| 操作 | 方法 |
|---|---|
| テキスト編集 | ダブルクリック、またはプロパティ |
| 複数選択 | Shift+クリック、または空白でドラッグ |
| 移動 | ドラッグ。Alt/Option でスナップを一時解除 |
| 複製 / 削除 | `⌘/Ctrl+D` / `Delete` |
| 元に戻す / やり直す | `⌘/Ctrl+Z` / `⌘/Ctrl+Shift+Z` |
| パン / ズーム | Space+ドラッグ / `⌘/Ctrl+スクロール` |
| 保存 / ダウンロード | `⌘/Ctrl+S` または `⌘/Ctrl+Enter` |

保存時はソースの該当範囲にパッチを当て、文書全体を再シリアライズしません。ブラウザーでは端末内で処理し、フォルダーサーバーはループバックアドレスで動作します。

対象は静的な `.html` と `.htm` です。プレビューではスクリプトと外部リソースをブロックするため、元の表示と異なる場合があります。SVG と canvas は保持しますが、内部の図形を個別の HTML 要素として編集できません。PPTX、Figma、draw.io、要素の親や順序の変更、リアルタイム共同編集には対応していません。[構成と制限（英語）](../docs/ARCHITECTURE.md)

## 開発

```sh
npm run check
npm run test:e2e
npm run test:browser
npm run test:extension
npm run build
```

テスト用ブラウザーのインストール：`npx playwright install chromium firefox webkit`。ローカルの Chromium テストでは、インストール済み Chrome を標準で使います。ウェブと拡張機能のビルドは出力を共有するため、順番に実行してください。
